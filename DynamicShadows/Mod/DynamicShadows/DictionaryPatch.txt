# Registers custom models in FFIX's GEO database.
# Format:  3DModel <geoId> <GEO_NAME>
# The geoId must be free: the game goes up to 5511 (FF9BattleDB.GEO.cs).
# The name must follow the pattern GEO_<type>_<version>_<code>; <type> decides the
# numeric subfolder (acc=1, main=2, mon=3, npc=4, sub=5).
# The FBX goes in: StreamingAssets/Assets/Resources/Models/4/9000/9000.fbx
#
# The cube below is a debug primitive: it tells a broken FBX apart from a broken
# field integration. It is not used by any map.
3DModel 9000 GEO_NPC_F0_CUB
